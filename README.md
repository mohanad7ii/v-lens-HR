# V-Lens HR

منصة توظيف وموارد بشرية عربية ثنائية اللغة، مبنية كواجهة Static على GitHub Pages مع Supabase للمصادقة والبيانات المحمية.

## الوحدات الرئيسية

- لوحة تحكم وقمع توظيف حي.
- قاعدة المرشحين ورفع السير الذاتية.
- AI Match ومقارنة المرشح بالوظائف.
- إدارة الوظائف والمرشحين المختصرين.
- جدولة المقابلات ونموذج تقييم موحد.
- العروض الوظيفية: إنشاء، موافقة داخلية، إرسال، قبول/رفض.
- التقارير والتحليلات.
- فريق التوظيف والأدوار والصلاحيات.
- صفحات HR إضافية للموظفين والحضور والإجازات والرواتب والأداء.

## Backend

المشروع متصل بـ Supabase ويستخدم:
- Auth للحسابات والجلسات.
- PostgreSQL مع Row Level Security.
- Storage للسير الذاتية.
- Edge Function لمعالجة CV.
- جداول: profiles, jobs, candidates, applications, interviews, evaluations, offers, activity_logs.

لا توجد Service Role Keys أو مفاتيح سرية داخل المتصفح؛ الواجهة تستخدم Publishable Key فقط.

## وضع الديمو

يمكن تجربة المنصة بدون حساب. بيانات الديمو ودرجات المطابقة التجريبية تحفظ محلياً في المتصفح عبر localStorage/sessionStorage، ولا يجب اعتبارها تحليلاً حقيقياً لملفات PDF أو قرار توظيف آلياً.

عند تسجيل الدخول بحساب حقيقي، تستخدم وحدات التوظيف الأساسية Supabase مع صلاحيات Admin / Recruiter / Manager.

## التشغيل

الموقع منشور عبر GitHub Pages. ويمكن تشغيل الملفات كواجهة static، لكن ميزات Supabase تتطلب اتصالاً بالإنترنت ونطاقاً مسموحاً في إعدادات Auth.

## الأمان

- RLS مفعّل على جداول التوظيف.
- الحذف محصور بدور Admin.
- إنشاء الوظائف والمرشحين والعروض محصور بأدوار التوظيف المناسبة.
- التقييم والتحديثات الإدارية مقيدة حسب الدور.
- ملفات CV في Storage محمية بسياسات وصول مرتبطة بالمستخدم.

## ملاحظة المنتج

V-Lens يقدم أدوات دعم قرار لفريق التوظيف. درجات المطابقة والتوصيات لا تستبدل المراجعة البشرية ولا ينبغي استخدامها كقرار توظيف آلي منفرد.
